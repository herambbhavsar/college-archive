# UNIT A — EYES, SENSES, INFORMATION

# T1 Visual ergonomics and introduction (Anshel, Ch. 1)
- Ergonomics = fit the task to the human; VISUAL ergonomics = make what people look at (signs, screens, labels, maps, rooms) match how eye and brain work. Eyes = "tools to catch light"; seeing happens in the brain; vision contributes most to interaction.
- Hunter-gatherer eye (Homo sapiens ~40,000 yrs ago): FRONTAL (overlapping fields → STEREOSCOPIC depth), HIGH on body (long range), keen DAY vision, adequate night vision, MOTILE (eye + head scanning).
- Mismatch today: ~16 h/day looking, artificial light, objects within arm's reach, small text, deadlines, little daylight → slow, imperfect adaptation; distance vision sacrificed for near.
| Era | Visual demand |
| Agricultural (till late 1800s) | Distance, daylight |
| Industrial (late 1870s, light bulb) | Night viewing; driving (distance + intermediate); near inspection of dials |
| Information (mid-20th c.) | Self-illuminated VDT (Video Display Terminal), awkward angle and distance — shift in < 100 years |
- Stats: computer users 10% (1980) → 80%+; 1991 Harris poll — eyestrain No. 1 office complaint; 1991 NIOSH (National Institute for Occupational Safety and Health) — 88% of 66 million (>3 h/day) had eyestrain; 2004 survey — 61% worried. Eyestrain overtook carpal tunnel but is painless/slow → misdiagnosed. Children not considered. Future: computer glasses; output always visual.

# T2 Special about the senses
- Vision dominates; takes in a LARGE amount SIMULTANEOUSLY; eye catches light → nerve signals → brain builds the picture.
- Senses = information channels (eyes, ears, skin, proprioceptors); brain = best processor. Vision for complex/spatial/long info; hearing for short urgent signals; touch for blind users or overload. Car: eyes read road, ears hear horn, hands feel steering.

# T3 Pertinence of the eyes (HFED)
- Eye: cornea → aqueous humor → pupil (iris: ~8 mm dark, ~2 mm bright) → lens (bulges for near, flattens for far) → vitreous → retina.
| Cones | Rods |
| 6–7 million, fovea | ~130 million, periphery (max 10–20°) |
| Bright light, colour, detail | Dim light, black & white |
- Fovea = sharpest; look slightly aside for dim objects. Eye vs camera: faster focus, wider light range, 3D, receptors face backwards. Accommodation; near/far point; DARK FOCUS ~1 m; diopters (1 D = 1 m, 2 D = 0.5 m). Elderly near point recedes → bigger labels.
- Information: direct or indirect via displays — CODED (warning light, siren) or REPRODUCED (TV, photo). DISPLAY = any indirect presentation. Dynamic (speedometer) vs static (sign).

# T4 Nonvisual modalities
- Hearing (attention-getting → VIGILANCE), touch/tactual (braille, shaped knobs), smell (gas odorant), proprioception. Sound for short, urgent, time-based messages; reserve sound for warnings (can't escape it; too many irritate). Examples: phone vibration, reversing beeper, F/J key dots.

# UNIT B — SYMBOLS, TYPE, COLOUR, LAYOUT

# T5 Icons, symbols and comprehension
- Visual capabilities: acuity improves to ~100–200 ms exposure; motion reduces acuity (dynamic acuity falls above ~60°/s); acuity & contrast decline after 40 (~20/30 at 75); training helps (+14% acuity, +32% contrast); dark adaptation: cones ~5 min, rods ~30–35 min.
- Symbols = CODING: detectability, discriminability, compatibility, meaningfulness, standardisation. Tests: recognition, matching, preference.
- Mandatory-action symbols (Cairney & Siess 1982, Vietnamese migrants): understood and REMEMBERED a week later → must be easy to learn. Exit signs (Collins & Lerner 1983, 18 designs): FILLED > outline; SQUARE background > circle; simpler better; "No exit" confused.

| Figure–ground | Clear separation from background |
| Figure boundary | Solid shape > outline |
| Closure | Closed shapes easier |
| Simplicity | Only necessary features |
| Unity | Parts form one unit |
| Code | Preferable limit |
| Surface colours | 9 (best for search & counting) |
| Colour of lights | 3 |
| Shapes | 5 |
| Angle | 12 |
| Size | 3 |
| Visual number | 4 |
| Brightness | 2 |

- Colour best for search (Christ 1975); letters/numbers best for identifying meaning; ≤ 2 code dimensions combined.

# T6–T7 Typeface, typography and colour
- Visibility → legibility → readability. Type matters most in poor viewing, critical info, distance, poor-vision users.
- Stroke width:height — black on white 1:6–1:8; white on black 1:8–1:10 (IRRADIATION); low light ~1:5; luminous 1:12–1:20. Width:height 3:5 (wider 1:1 for back-lit/engraved).
- Type classes: Roman (serif), Gothic (sans serif — signs/labels), Script, Block. Italics for emphasis; bold for headings & poor conditions.
- Size: 1 pt = 1/72 in (slug); cap height ≈ 1/100 in per pt; reading distance ~35 cm, 9–11 pt fine; signs for 20/40 acuity.
- CASE: lowercase > ALL CAPS (word envelope); bigger initial letter helps search. SPACING: close-set type read faster; more interline space reduces striped-pattern discomfort.
- WORDING: simple, affirmative, active; word order = action order ("Turn off the gas before pushing the green button"). Flesch = 206.835 − 0.846 × syllables − 1.015 × words/sentence (60–70 standard; 90–100 very easy).
- COLOUR: best for search/counting; few colours for untrained users; always REDUNDANT with text/shape (colour-blind, lighting); contrast essential.

# UNIT C — DISPLAYS AND CRITICAL INFORMATION

# T10 Digital displays and railway reservation form
- Know information needs (situation awareness): check vs qualitative vs quantitative reading (engine light + gauge).
- DIGITAL when exact value and it stays long enough; ANALOG (fixed scale, moving pointer) for changing values, direction/rate. Heglin: moving pointer on fixed scale; vertical scale for "up = more"; don't mix indicator types; control moves pointer; small changes visible.
- Coded zones (green/yellow/red); dials aligned at 9 o'clock (gestalt); status indicators; traffic light = colour + position redundancy.
- Warning lights: ≥ 2× background brightness, within 30° of line of sight, RED, ≥ 1° visual angle, ≤ 3 flash rates.
- Representational displays → situation awareness; templates/schema (red tail-lights = slowing).
- Auditory principles: compatibility, approximation (attention + designation signals), dissociability, parsimony, invariance; avoid extremes, set relative to noise, interrupted signals, don't overload (Three Mile Island 60+ alarms); test with users.
| Alarm | Attention / penetration |
| Diaphone (foghorn) | Good / poor in low-freq noise |
| Horn | Good / good |
| Whistle | Good if intermittent |
| Siren | Very good with rising-falling pitch |
| Bell | Good / good in low-freq noise |
| Buzzer, chimes | Fair |
| Oscillator | Good if intermittent |
- Railway form: fields in action order (journey → passengers → contact → payment); clear left labels; avoid confusable PNR (Passenger Name Record) characters; digital for exact values; status AVAILABLE / RAC (Reservation Against Cancellation) / WL (Waiting List) with colour + text.

# T9 & T11 Pesticide packaging; critical context (verify)
- Pesticides: low-literacy farmers, sun, gloves → pictograms, toxicity colour TRIANGLE (red extremely, yellow highly, blue moderately, green slightly toxic), local language, visual dose, non-food shape, child-resistant cap.
- Critical context (Callan, medical device labelling): design for real context (stress, night, noise); critical info first and prominent; consistent location; plain active words; step order = action order; contrast; colour redundant; standard symbols; warnings with signal word + hazard + consequence + avoidance.

# T12 Better drug labelling for pharmacists (Quinn et al. 2006)
- 51.5 million dispensing errors/3 billion prescriptions (98.3% accurate); 250/day pharmacy ≈ 4 errors/day; clinically important 1 in 1000.
- 9 error types (wrong drug, strength, dosage form, quantity, label info, instructions, omission, time, deteriorated) — label influences drug, strength, form, deterioration.
- Label anatomy: NDC (National Drug Code), brand, generic, formulation, strength, quantity, controlled symbol, Rx only, maker, expiry, lot, storage.
- Key of 30 guidelines: brand name largest; generic slightly smaller; strength & ER near name; NDC on top; expiry/lot on front; horizontal reading; 8th-grade language; dark on light; ≥ 7 pt; one font family; colour redundant; left-aligned; mixed case (WARNING in caps); no italics; no clutter/watermarks; margins; line drawings of tablets; few boxes.
- New template: low density, black on white, order brand → generic → strength → NDC, red for form/alerts. Test: 20 pharmacists, real bottles + EYE TRACKING, 60 labels, imaginary drug names → "after" labels faster on ALL tasks; biggest gains where old labels were unclear.

# T14 Road safety through VE (Netherlands)
- Self-explaining roads; "death roads"; 103 drivers rated 14 slides (crosses, mourning cards, text "snel?/haast?").
| Sign | Danger | Speed |
| Text only | 27% | 93% |
| Text + roadside crosses | 70% | 82% |
| Crosses only | 52% | 18% |
| Mourning cards | 23% | 4% |
- Crosses add DANGER without losing speed meaning; mourning cards not recognised; ~67% didn't want death symbols; "In a hurry?" wanted (75%). PLEASING ≠ SAFE; rumble strips cut accidents 15–20%; brick streets in Haren; wordy on-ramp sign caused a crash.

# T15 Password ergonomics (Moallem 2004)
- 30 log-in pages: 7 components (title, username, password, button, forgot password, forgot username, help) but inconsistent labels (8 button labels), label above (47%) vs left (53%).
- Users: "Login" title 74%, "User ID" 42%, "Password" 95%. STANDARD: title Log-in, User ID, Password, button Log-in, "Forgot Your User ID?", "Forgot Your Password?", "Help?"; left-aligned plain labels; same word for title & button → CONSISTENCY.

# T16 Airport taxiway markings (FAA)
- Runway incursion = collision hazard on runway; 1,480 (1999–2002); 833 deaths since 1972; causes: memory decay, interruption, miscommunication, disorientation. PAINT = cheap, simple, universal.
- 10 goals: all eye heights (8–20 ft), conspicuity, directionality, preview, awareness not force, intuitive, unique on several dimensions, compatible, consistent, keep yellow = taxiway / white = runway.
- Process: everyone incl. PAINT CONTRACTORS from the start; 20 concepts → 5 → simulator (36 pilots) → field (224 pilots).
| Marking | Why |
| Dashed taxiway centreline (150 ft before hold line) | Preview where pilots already look |
| Red surface-painted holding signs | Red = runway; upside-down when leaving; seen 20 ft sooner |
| Hold line dashes WHITE + extended | White = runway side; visible past the nose |
- Combined cues detected ~20 ft earlier than best single cue — redundancy; whole > sum.

# T17 London Underground map (Degani)
- Geographic map (1932) confusing → Harry Beck (draughtsman) diagram 1933 ("the Diagram"); navigation INSIDE the network matters, not geography.
- ABSTRACTION: lines at 0°, 90°, 45°; ticks for stations, rings for interchanges. INTEGRATION: interchange complexes as units (Aldgate triangle). CONFIGURATION: grid, symmetry along Central Line, strong centre (Circle Line "water flask"), expanded centre / shrunk outskirts, Thames kept. Diagonals restored after removal. Victoria Line proposal = design for users over time.
- 5 formal principles: skeletal grid of landmarks; keep relative orientation; consistent N/S/E/W; few line angles; minimum direction changes. Delhi/Mumbai metro maps follow Beck.

# UNIT E — SAFETY, WARNINGS, ENFORCEMENT

# T18 Poison to the touch (Senders; Bogner)
- KCl injected instead of Lasix (death); lidocaine 20% vs 2% syringes (100+ deaths; withdrawn 1992, not recalled). People "see what they expect" → use TOUCH as parallel channel ("prickly = don't inject"); colour could cut errors 90%.
- 1857 Poisons Bill: quadrangular BLUE glass, white-on-black "POISON", EMBOSSED on 4 sides (black warning ground, max contrast, can't be covered, touch + visual cues). 1868 Pharmacy Act — bottles distinguishable by touch; patents: spines, puzzle caps.
- Bogner: look-alike ampoules & names (Hiprex/Herplex); adverse drug events 19.4% of injuries; workers ACCOMMODATE instead of complain; red syringes for relaxants (Australia), colour-coded labels (Hadassah); system problem — "change the script, not the actor".

# T19 Warnings (Wogalter et al., 150+ studies)
- 4 elements: SIGNAL WORD, HAZARD, CONSEQUENCE, INSTRUCTION. Signal words: DANGER > WARNING > CAUTION > NOTICE (DEADLY/POISON higher).
- Red = highest hazard; conspicuity first (size, contrast, flashing); PLACEMENT near hazard, uncluttered; brief but explicit; bullets > paragraphs; pictorials (ISO (International Organization for Standardization) 67%, ANSI (American National Standards Institute) 85% comprehension, ≤ 5% opposite); borders/striped increase urgency; voice increases compliance; false alarms reduce it; familiarity lowers noticing; risk judged by severity; interactive warnings best; older people need larger print; warnings don't reduce buying.
- Model: ⚠ DANGER · High voltage · Contact will cause severe burns or death · Keep out — authorised staff only.

# T20 Truck "wide turn" signs (Aurelio & Newman 1997)
- Wide right turns hit cars on the right; signs voluntary, unregulated; 25 signs photographed on I-95, judged by 5 experts.
- Varied in colour, view, text/diagram, signal word, orientation, sketch, information. None stated CONSEQUENCE in words; instructions vague.
- Improved: "CAUTION — Wide right turns. Yield the right of way to truck."; signal word on top; side-view collision sketch with starburst; black mixed-case left-aligned text on white/yellow.

# T21 Parking enforcement (Chicago 1990)
- 10% tickets paid, 17 million unpaid ($420 m) → 10 months to redesign → payment 65%, $65 m/year, only 7% contested, almost no confused calls.
- Systems thinking (image-based adjudication); ticket = touches whole system → concurrent team (users, vendors, beat police, graphic designer); pocket-size book; 9 violations = 80% → CHECK BOXES; handwriting on LEFT (right-handers standing); white front, ORANGE back with adhesive strip (forcing); handheld defaults; instructions tested until no misreading; users' MENTAL MODEL of 3 options adopted. Lessons: business language, design as investment, compare with current design.

# UNIT F — ILLUSION, ELECTIONS, WAYFINDING

# T22 Jugglery with colour (Williams 2012)
- Healthcare contains unintended "magic"; clinicians blamed. Good design = no trickery (feedback, recognition not recall, readable labels, don't lie).
| Trick | Healthcare illusion → fix |
| Card trick | Lab report hid 0% neutrophils → show ALL values |
| Same substance, many forms | Eye vs orthopaedic sodium hyaluronate in similar WHITE-BLUE packs → distinct packaging/colour |
| Magic rope | Cerebyx/Celebrex/Celexa → TALL MAN lettering |
| Disappearing ball | Therac-25, ventilator stuck → clear status & feedback |
| Frog-and-penny | Bile duct looks like cystic duct → mental model shapes perception |
| Things that fit belong | Luer misconnections → unique connectors |
| Inattentional blindness | Integrated trend displays |

# T23 Visual ergonomics in voting (Gable et al. 2016)
- US turnout 31st/34; 2000 Florida BUTTERFLY BALLOT → ~50,000 votes discarded; 11% ballots with errors.
- Process: one-stop website, voter accounts (recognition not recall), appointments (prediction aiding). Ballot: progress meter (system status), final check (error prevention), receipt & green-tick feedback with actionable error messages, reversibility, accessibility (size, language, audio, tactile), consistent layout, practice ballot, RANDOMISED candidate order (F-pattern bias).
- India: EVM (Electronic Voting Machine) name + symbol + photo, beep, VVPAT (Voter Verifiable Paper Audit Trail) slip 7 s, NOTA (None Of The Above) last.

# T25 Wayfinding for older adults (Watson 2001)
- Bob's courthouse story (garage dark, "LL" buttons, tiny map, glare). Wayfinding = what people SEE, THINK, DO to move; abilities: sensory-perceptual, cognitive, motor; "without signs, a guessing game".
| Ability | Guideline |
| Vision | Black on white/yellow, non-reflective; outside letters 10–13 cm, inside 1.6–5 cm; transition lighting |
| Attention | ≤ 7 words |
| Memory | Level & space numbers; next sign visible from last |
| Cognition | "Lobby", "Sub 1"; trained staff; printed maps |
| Orientation | Forward-up You-Are-Here maps, N/S/E/W, landmarks; sign at every decision point |
| Safety | Emergency call devices; lighting |
- Age declines: acuity, field of view, glare recovery, blue-green, presbycusis (avoid > 3000 Hz), working & spatial memory, speed, walking −10–20%/decade after 60. Supports: light, contrast, big print, seating, wide corridors, handrails, slow lift doors. Design as a SYSTEM; "know thy user".

# UNIT G — HOSPITALS, LAW, TRANSPORT

# T24 Hospital information
- ED (Emergency Department) LaunchPoint (Cerner): UCD (User-Centred Design) with 72 ED physicians; pain points (non-actionable icons, clicks, icon key taped on monitor, clutter, >10 s waits). Redesign: one icon per order category + colour progress; note icons (blank/text/green check/pencil); LOS (Length of Stay) meter digital + colour bar; one modal "drill-down" panel; validated with 12 physicians.
- Urine bag (Indonesia 2026): floats + enlarged high-contrast scale + colour bands → lower error at 2–7 m, reliable distance +2 m (~6.4 m). Small, cheap changes reduce error.
- Checklists: origin 1935 Boeing 299 crash (gust lock); Johns Hopkins central line (infections 11% → 0%); WHO Surgical Safety Checklist (19 items; complications 11% → 7%). READ-DO vs DO-CONFIRM; benefits (memory, fatigue, standardisation, best practice, teamwork); barriers & solutions (involve users).
- Medication sheets (Klein & Isaacson): old 9 pt, caps, justified, 12th-grade → new 14 pt, ragged right, plain 9th-grade active language, task order, bold headings, side-effect boxes → faster, more correct, ~90% preferred.

# T27 Bus stand and aircraft interior
- F-4 night near-crash: "I've got it" misunderstood → nobody flying; Type 1 SPATIAL DISORIENTATION (canals miss < 2°/s² roll); handover protocol. Attitude indicator: moving horizon vs moving aircraft (principle of the moving part); needs FOVEAL fixation. Redesign: context-aware audible "BANK RIGHT" + visual cue; alert early; automatic ground-collision avoidance.
| Bus stand area | VE (Visual Ergonomics) solution |

| Bus destination boards | LED (Light-Emitting Diode), 1/200 rule, number + colour + name |
| Route maps | Beck-style schematic, You-Are-Here forward-up |
| Announcements | Audio + visual |
| Timetables | Grouped, next departure highlighted |
| Wayfinding | Standard pictograms, reassurance, every decision point |
| Elderly/disabled | Ramps, seating, lighting, tactile paving |
| Safety | Yellow edge lines, warnings with consequence |
