# College Archive

B.Des study website: notes, PPTs, PYQs, resources, assignments and quick tests for all 8 semesters.

- `index.html` — the whole site (static, no build step)
- `notes/` — Sem 5 revision notes (Markdown), shown with a left topic index and scroll-spy
- `tests.json` — quick-test questions per course

Run locally: `python3 -m http.server` in this folder, then open http://localhost:8000.
